Java Script Variables

1. What is a variable?

A variable is a named storage location in a computer's memory that holds a value. Think of it like a labeled box where you can store data (like a number, text, or true/false) that can change while the program runs.

Example: age = 25 → Here, age is the variable holding the value 25.

2. What is declaration?

Declaration is the act of creating a variable by specifying its name and, in some languages, its type. It tells the computer, "I’m going to use a variable with this name."

Example: let score; This declares a variable named score without giving it a value yet.

3. What is initialization?

Initialization is assigning a value to a variable for the first time (usually at the same time as declaration, but not always).

Example: let score; let score = 10; Declares score and initializes it with 10.

4. Three types keywords?

In programming, "keywords" are reserved words with special meanings.

  1. var
  2. let
  3. const

5. What is compiler in JS and its name?

JavaScript is generally an interpreted language, not a compiled one. However, modern JS engines use Just-In-Time (JIT) compilation to improve speed.

The main JS engine (compiler + runtime) names are:

  • V8 (Google Chrome, Node.js)
  • SpiderMonkey (Firefox)
  • JavaScriptCore (Safari)
  • Chakra (older Edge)

So, the most famous "compiler" name for JS is V8.

6. What are printing statements?

Printing statements are commands that output data to the console (terminal) or screen, mainly for debugging or showing results to the user.

Example: onsole.log("Hello, World!"); Prints "Hello, World!" in the browser's console or terminal.
