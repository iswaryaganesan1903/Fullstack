Database Concepts

1. RDBMS (Relational Database Management System)

RDBMS is software used to store and manage data in the form of tables. Each table contains rows and columns, and tables can be related using primary keys and foreign keys.

Examples: MySQL, PostgreSQL, Oracle, SQL Server.

2. SQL (Structured Query Language)

SQL is the standard language used to communicate with relational databases. It is used to create, read, update, and delete data.

Common Commands: CREATE, INSERT, SELECT, UPDATE, DELETE, DROP.

3. MySQL

MySQL is a popular open-source Relational Database Management System (RDBMS). It stores data in tables and uses SQL to manage data.

4. MySQLi

MySQLi (MySQL Improved) is a PHP extension used to connect PHP applications with a MySQL database.

It supports prepared statements, transactions, and improved security.

5. PostgreSQL (PG)

PostgreSQL (PG) is an advanced open-source relational database known for high performance, reliability, and support for complex queries.

6. Oracle Database

Oracle Database is a commercial RDBMS developed by Oracle Corporation. It is widely used in banking, healthcare, government, and large enterprise applications.

7. Server

A server is a computer or software that provides services, data, or resources to other computers (clients) over a network.

Example: A database server stores and provides database services.

8. XAMPP

XAMPP is a free software package that includes:

  • Apache Web Server
  • MySQL (MariaDB)
  • PHP
  • Perl

It is mainly used to run PHP and MySQL applications on a local computer.

9. WAMP

WAMP stands for:

  • Windows
  • Apache
  • MySQL
  • PHP

It is similar to XAMPP but is designed only for Windows.

10. GUI (Graphical User Interface)

GUI is a visual interface that allows users to interact with software using buttons, icons, menus, and windows instead of typing commands.

Example: MySQL Workbench provides a GUI to manage databases.

11. MySQL Workbench 8

MySQL Workbench 8 is a graphical tool used to manage MySQL databases. It helps users create databases, write SQL queries, design tables, manage users, and back up databases.

Features:

  • Create and manage databases
  • Write and execute SQL queries
  • Design ER diagrams
  • Manage tables and relationships
  • Import and export data
  • Backup and restore databases
