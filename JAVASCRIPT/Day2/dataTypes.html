Primitive Data Types

  1. Number:Represents both integers and floating-point numbers.
  2. String:Represents textual data.
  3. Boolean:Logical values: true or false.
  4. Bigint:For larger integers
  5. Undefined:Variable declared but not assigned a value.
  6. Null:Represents "nothing", "empty", or "value unknown".
  7. NaN: Invalid or unrepresentable number

Non Primitive Data Types

Non-primitive data types in JavaScript are data types that can store multiple values and more complex data.
