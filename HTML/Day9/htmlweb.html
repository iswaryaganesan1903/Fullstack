HTML Full Process

HTML

HTML (HyperText Markup Language) is the standard markup language used to create and design web pages. It structures the content on the web using elements like headings, paragraphs, links, images, etc.

Tags

Tag is predefined keyword in html enclosed inside angle bracket.Tags are used to tell browsers what type of content should be displayed on the webpage.

HTML contain 3 types of tags:Closing tags,Self closing tags and Empty tags

1.Closing tags:

Closing tags have two pairs which are opening and closing tags. For example, html,head,body,h1,h2,h3,h4,h5,h6,p these all are closing tags.

2.Self closing tags:

A self-closing tag is a tag that does not need a separate closing tag because it completes its action by itself. For example,br,hr,img and input tags are the self closing tags.

3.Empty tags:

An empty tag is a tag that does not contain any content and does not need a closing tag.

Elements

An element is a complete structure format contains opening and closing tags and in between content or having collection of elements.

HTML contain 3 types of elements:Root element,Container element and Child element

Semantic Tags

Semantic tags clearly describe their meaning to both the browser and developer. They improve accessibility and SEO.

Examples:

header, footer, article, section, nav, aside, main, summary, figure, mark

Non Semantic Tags

Non-semantic tags do not convey any meaning about their content. They are used purely for styling or layout purposes.

Examples:

div,span

Attributes

Attributes provide additional information about an HTML element. They are written inside the opening tag.

Global Attributes

Global attributes are attributes that can be used with almost all HTML elements.

Examples:
  • class="container" - Defines class name for styling or grouping elements
  • id="header" - Defines unique identifier for an element
  • style="color:red;" - Applies inline CSS style to an element
  • title="message" - Displays extra information as tooltip
  • hidden - Hides the element from webpage

Local Attributes

Local attributes are attributes that are used only with specific HTML elements.

Examples:
  • href="https://example.com" - Defines hyperlink URL in a tag
  • src="image.jpg" - Defines image or media source path
  • alt="description" - Defines alternative text for image
  • type="text" - Defines input type in input tag
  • placeholder="Enter Name" - Displays hint text inside input field
  • controls - Adds controls for audio or video tags

Form Tag

The form tag is used to collect user input from a webpage. It is mainly used for login forms, registration forms, surveys, feedback forms, and more.

Common Form Elements

Examples:
  • input - Creates input fields like text, password, email, etc.
  • label - Defines label for input field
  • textarea - Creates multi-line text box
  • select - Creates dropdown list
  • option - Defines options inside dropdown
  • button - Creates clickable button
  • fieldset - Groups related form elements
  • legend - Defines title for fieldset

Common Form Attributes

Examples:
  • action="submit.php" - Specifies where form data should be sent
  • method="post" - Specifies HTTP method for sending data
  • target="_blank" - Opens response in new tab
  • autocomplete="on" - Enables auto suggestion in form fields
  • required - Makes input field mandatory
  • placeholder="Enter Name" - Displays hint text inside input field

Table Tag

The table tag is used to display data in rows and columns on a webpage.

Common Table Elements

Examples:
  • table - Creates a table
  • tr - Defines table row
  • th - Defines table heading
  • td - Defines table data cell
  • caption - Defines table title
  • thead - Groups table header content
  • tbody - Groups main table body content
  • tfoot - Groups table footer content

Common Table Attributes

Examples:
  • border="1" - Adds border to table
  • cellpadding="10" - Adds space inside table cells
  • cellspacing="5" - Adds space between table cells
  • rowspan="2" - Merges rows
  • colspan="2" - Merges columns
  • align="center" - Aligns table content

Meta Tag

The meta tag provides information about the webpage to browsers and search engines. It is written inside the head section.

Common Meta Attributes

Examples:
  • charset="UTF-8" - Defines character encoding
  • name="description" - Defines webpage description
  • content="HTML Tutorial" - Specifies metadata content
  • name="keywords" - Defines webpage keywords
  • name="author" - Defines author name
  • http-equiv="refresh" - Refreshes webpage automatically

Difference Between HTML and HTML5

HTML HTML5
Older version of HTML Latest version of HTML
Does not support audio and video directly Supports audio and video using audio and video tags
Uses lengthy doctype declaration Uses simple doctype declaration
Limited semantic elements Provides semantic tags like header, footer, section, article
Does not support local storage Supports local storage and session storage
Works less efficiently with multimedia Improved multimedia support
