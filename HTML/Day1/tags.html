Tags

There are two types of tags in html
1.Closing tags
2.Self closing tags

Closing tags

Closing tags have two pairs which are opening and closing tags.
For example, html,head,body,h1,h2,h3,h4,h5,h6,p these all are closing tags.

Self closing tags

A self-closing tag is a tag that does not need a separate closing tag because it completes its action by itself.
For example,br,hr,img and input tags are the self closing tags.

Empty tags

An empty tag is a tag that does not contain any content and does not need a closing tag.
