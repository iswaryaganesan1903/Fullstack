What is CSS?

  • CSS stands for Cascading Style Sheets is a stylesheet language used to describe the presentation of a document written in HTML
  • It also used control the layout, colors, fonts, spacing, and responsiveness of web pages. It separates content (HTML) from design, making sites easier to maintain and update.

What are the three types of CSS?

  1. Inline CSS
    2.

    Inline CSS is written directly inside an HTML element using the style attribute.

    Syntax: <tagname style="property: value;">

  2. Internal CSS
    3.

    Internal CSS is written inside a <style> tag within the <head> section of an HTML document. It is mainly used for single-page websites, testing, or quick styling experiments.

    Syntax: <style> selector { property: value; } </style>

  3. External CSS
    4.

    External CSS is the best and most commonly used method for styling websites. The CSS code is written in a separate .css file and linked to the HTML document using the <link> tag. This method keeps the code clean, reusable, and easy to manage.

    Syntax: <link rel="stylesheet" href="filename.css">

    CSS File Syntax: selector { property: value; }

What are CSS Selectors?

  • CSS selectors are used to select HTML elements and apply styles to them.
  • They help the browser identify which elements should be styled according to the CSS rules.
  1. Universal Selector (*)
    2.

    The universal selector selects all HTML elements on a web page.

    Syntax: * { property: value; }

  2. Element Selector
    3.

    The element selector selects all elements of a specific HTML tag.

    Syntax: tagname { property: value; }

  3. Class Selector (.)
    4.

    The class selector selects elements with a specific class attribute. A class can be used on multiple elements.

    Syntax: .classname { property: value; }

  4. ID Selector (#)
    5.

    The ID selector selects an element with a specific ID attribute. An ID should be unique within a page.

    Syntax: #idname { property: value; }

  5. Group Selector (,)
    6.

    The group selector is used to apply the same styles to multiple elements.

    Syntax: selector1, selector2 { property: value; }

  6. Descendant Selector (space)
    7.

    The descendant selector selects elements that are inside another element.

    Syntax: parent child { property: value; }

  7. Child Selector (>)
    8.

    The child selector selects only direct child elements of a parent element.

    Syntax: parent > child { property: value; }

What is Box model?

It is a core method to handle the layout and design.

They have four parts:

  • Content
  • Padding
  • Border
  • Margin

These are the four pillars of box model.

  1. Content:
    2.

    The content area is the innermost part of an element where the actual information, such as text, images, videos, or other HTML elements, is displayed. By default, the width and height properties in CSS apply to the content area.

  2. Padding:
    3.

    Padding is the space between the content and the border. It creates inner spacing within an element, making the content appear less crowded. Padding increases the visible size of the element and can be applied individually to the top, right, bottom, and left sides.

  3. Border:
    4.

    The border is a line that surrounds the content and padding. It helps define the boundaries of an element and can be customized with different widths, styles, and colors. Borders are commonly used to highlight or separate elements on a webpage.

  4. Margin:
    5.

    Margin is the outermost space around an element, outside the border. It creates distance between the element and neighboring elements, helping to improve layout and readability. Unlike padding, margins do not affect the element's background color and are always transparent.

What is Coloring in CSS?

Coloring in CSS is used to apply colors to text, backgrounds, borders, and other elements on a webpage. It helps improve the appearance, readability, and user experience of a website.

CSS provides different types of color values:

  1. Color Names:
    2.

    CSS supports predefined color names such as red, blue, green, yellow, black, and white. These names can be directly used to apply colors to elements.

  2. HEX Colors:
    3.

    HEX (Hexadecimal) colors are represented using a hash symbol (#) followed by six hexadecimal characters. They define the intensity of red, green, and blue colors.

  3. RGB Colors:
    4.

    RGB stands for Red, Green, and Blue. Each color value ranges from 0 to 255, allowing a wide range of color combinations.

  4. RGBA Colors:
    5.

    RGBA is similar to RGB but includes an Alpha value that controls transparency. The alpha value ranges from 0 (fully transparent) to 1 (fully visible).

What is Pseudo Classes?

A Pseudo Class is used to define the special state of an element. It is represented using a single colon (:). Pseudo Classes are commonly used for user interactions such as hovering, focusing, or selecting elements.

  1. :hover
    2.

    Applies styles when the user places the mouse pointer over an element.

  2. :active
    3.

    Applies styles when an element is being clicked by the user.

  3. :focus
    4.

    Applies styles when an input field or form element receives focus.

  4. :visited
    5.

    Applies styles to links that have already been visited by the user.

What is Pseudo Elements?

A Pseudo Element is used to style a specific part of an element. It is represented using a double colon (::). Pseudo Elements allow styling of content that is not directly present in the HTML.

  1. ::before
    2.

    Inserts content before the actual content of an element.

  2. ::after
    3.

    Inserts content after the actual content of an element.

  3. ::first-letter
    4.

    Styles only the first letter of an element's content.

  4. ::first-line
    5.

    Styles only the first line of an element's content.

What is Position in CSS?

The position property in CSS is used to control how an element is placed on a webpage. It helps developers arrange elements at specific locations relative to their normal position, parent element, or browser window.

Types of Position in CSS:

  1. Static:
    2.

    Static is the default position value for all HTML elements. Elements are displayed in the normal document flow, and properties like top, right, bottom, and left do not work.

  2. Relative:
    3.

    Relative positioning moves an element from its original position without affecting the layout of surrounding elements. It works with top, right, bottom, and left properties.

  3. Absolute:
    4.

    Absolute positioning removes the element from the normal document flow and positions it relative to its nearest positioned parent element.

  4. Fixed:
    5.

    Fixed positioning places an element relative to the browser window. The element remains in the same position even when the page is scrolled.

  5. Sticky:
    6.

    Sticky positioning combines the behavior of relative and fixed positioning. The element behaves like relative until a specified scroll position is reached, then it becomes fixed.

What are Media Queries?

Media Queries are a feature in CSS used to make webpages responsive. They allow developers to apply different styles based on the screen size, device type, or screen resolution.

Media Queries help websites look good on desktops, laptops, tablets, and mobile phones by adjusting layouts, font sizes, images, and other design elements according to the available screen space.

Common Types of Media Queries:

  1. max-width:
    2.

    Applies styles when the screen width is less than or equal to a specified value. It is commonly used for mobile and tablet devices.

  2. min-width:
    3.

    Applies styles when the screen width is greater than or equal to a specified value. It is commonly used for larger screens.

  3. Orientation:
    4.

    Applies styles based on the device orientation, such as portrait or landscape mode.

What is the Difference Between CSS and CSS3?

CSS CSS 3
Older version of CSS. Latest and improved version of CSS.
Limited design and animation features. Provides advanced animations and transitions.
Does not support media queries. Supports media queries for responsive design.
Basic color formats such as color names, HEX, and RGB. Introduces RGBA, HSL, and HSLA color formats.
No support for flexible layouts. Supports Flexbox and Grid layouts.
Limited border and background styling options. Provides border-radius, box-shadow, gradients, and multiple backgrounds.
Developed as a single large specification. Divided into separate modules for easier development and updates.
