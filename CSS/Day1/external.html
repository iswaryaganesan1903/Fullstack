CSS

What is CSS?

CSS stands for Cascading Style Sheets. CSS is used to design and style HTML webpages. It controls colors, fonts, layouts, spacing and visual appearance. HTML creates the structure while CSS improves the presentation.

The Evolution of CSS

  • 1996: CSS1 released (basic fonts, colors, margins).
  • 1998: CSS2 released (positioning, z-index, media types for print).
  • 2011+: CSS3 modular approach (animations, transforms, gradients, flexbox, grid).
  • Today: CSS is incredibly powerful. Features like Flexbox (one-dimensional layout), CSS Grid (two-dimensional layout), Custom Properties (CSS Variables), and Container Queries have turned CSS from a simple styling language into a true design tool.

The Core Concept: "Separation of Concerns"

CSS was invented to solve a fundamental problem: keeping content and style separate.

Without CSS : You would have to manually add font, color, and bgcolor attributes to every single HTML tag. Imagine changing the color of 1,000 "Buy Now" buttons by hand.

With CSS: You write one rule (e.g., p { background-color: red; }), and it automatically applies to every button on every page of your website.

This separation provides three massive benefits:
  1. Maintainability: Change one line of CSS to update your entire website.
  2. Speed: Browsers download the CSS once and cache it (remember it) for all pages.
  3. Accessibility: Designers can work on the CSS without breaking the HTML structure, making it easier to create accessible sites for screen readers.

How CSS Works

Cascade:

The "C" in CSS (Cascading) is its most important and unique feature. The cascade is the algorithm that resolves conflicts when multiple CSS rules target the same HTML element.

Style:

The "Style" in CSS refers to the visual presentation rules that transform raw HTML into a designed interface.The style categories are Typography,Colors & Backgrounds,Box Model,Layout,Animations,Responsive Design.

Sheet:

The "Sheet" in CSS refers to a collection or document of multiple style rules. Think of it like a spreadsheet or a cheat sheet—a single file containing many instructions.

The Three Ways to Apply CSS

External CSS:

External CSS is the best and most commonly used method for styling websites. The CSS code is written in a separate .css file and linked to the HTML document using the <link> tag. This method keeps the code clean, reusable, and easy to manage.

Internal CSS:

Internal CSS is written inside a <style> tag within the <head> section of an HTML document. It is mainly used for single-page websites, testing, or quick styling experiments.

Inline CSS:

Inline CSS is written directly inside an HTML element using the style attribute. It is generally avoided because it makes the code harder to maintain, but it can be useful for small changes, emergency overrides, or dynamic styling.
